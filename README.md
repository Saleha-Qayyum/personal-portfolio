## 🚀 Getting Started

### Prerequisites

* Node.js 18+
* npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Saleha-Qayyum/personal-portfolio.git

# Navigate to the project
cd personal-portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
